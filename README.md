# Java Unit Testing

**Java · JUnit 4 · Mockito · JaCoCo**
Учебный проект Яндекс Практикума.

Unit-проверки модели животных.

## Подход к тестированию

- **Позитивные сценарии:** значения звука, рациона, семейства и количества котят.
- **Негативный сценарий:** исключение и текст ошибки для недопустимого пола льва.
- **Параметризация:** два допустимых значения пола проверяются одним сценарием.
- **Dependency Injection:** зависимость `Feline` передается в `Lion` через конструктор.
- **Mockito:** поведение зависимости задается явно при проверке логики льва.
- **JaCoCo:** отчет позволяет связать сценарии с затронутыми участками исходников.

## Технологии

- Java, Maven;
- JUnit 4;
- Mockito;
- JaCoCo.

## Что проверяется

- Звук и получение еды у кошки.
- Рацион хищника и семейство кошачьих.
- Количество котят по умолчанию и при переданном значении.
- Наличие гривы у льва для двух допустимых значений пола.
- Исключение и его сообщение при недопустимом значении пола льва.
- Получение еды и количества котят у льва с подмененной зависимостью.

## Структура

```text
src/main/java/com/example/     # модель животных
src/test/java/                 # Cat, Feline, Lion и параметризация
pom.xml                        # зависимости и JaCoCo
target/site/jacoco/             # отчет о покрытии
```

## Запуск

Скачайте исходники `main`, распакуйте их и откройте терминал в каталоге с `pom.xml`.

```bash
mvn verify
```

JaCoCo формирует отчет на фазе `verify`. После успешного выполнения откройте `target/site/jacoco/index.html`.

## Результаты и отчетность

HTML-отчет JaCoCo показывает покрытие по классам и подсветку исходников.

Фокус проекта — unit-уровень: ожидаемые значения, исключения, параметризация и работа с зависимостями.
